# Paite IDPs Committee, Jiribam Website

Static website prepared for GitHub Pages.

## Publish
1. Create a public repository named `pidp2026.github.io` under GitHub account `PIDP2026`.
2. Upload all files and folders in this package.
3. Go to Settings -> Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for deployment.
7. Open https://pidp2026.github.io/

Replace placeholder photos and document links with approved official materials before publication.
